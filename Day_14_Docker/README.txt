# Day 14: Docker Fundamentals

## Objective
Learn how to package and run a Python application using Docker.

## Files
- `app.py` — Python application.
- `Dockerfile` — Instructions for building the Docker image.

## Commands Practised
- `docker --version`
- `docker run hello-world`
- `docker images`
- `docker ps`
- `docker ps -a`
- `docker build -t my-first-python-app .`
- `docker run --name python-demo my-first-python-app`

## Result
Successfully built a Docker image and ran a Python application inside a container.
