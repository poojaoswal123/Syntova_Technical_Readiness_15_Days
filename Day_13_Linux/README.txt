# Day 13: Linux Command Line

## Objective
Practise basic to intermediate Linux commands using Ubuntu through WSL.

## Topics Covered
- Directory navigation: `pwd`, `ls`, `cd`
- File management: `mkdir`, `touch`, `cat`, `cp`, `mv`
- Text searching: `grep`, `find`, `head`, `tail`, `wc`
- Pipes and output redirection
- Basic permissions and environment variables
- Shell scripting

## Practical Work
- `linux_practice.sh` — Demonstrates common Linux commands.
- `day13_summary.sh` — Analyses an application log and generates an error report.
- `data/app.log` — Sample application log.
- `reports/` — Generated error reports.

## Result
Successfully practised Linux command-line operations and automated basic log analysis using Bash.
